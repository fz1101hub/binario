# Documenti storici di progetto e release

Questa directory raccoglie specifiche, benchmark, palette, matrici funzionali e note di implementazione delle versioni precedenti di Binario. I documenti sono conservati per tracciabilità, ma possono descrivere architetture, nomi, schermate o comportamenti successivamente sostituiti.

La documentazione corrente resta in [`../../`](../../), mentre i rapporti di verifica storici sono in [`../../verifiche/`](../../verifiche/). Le decisioni architetturali correnti hanno precedenza sui contenuti di questa directory.

Nuovi documenti temporanei di sessione e file `todo*.md` non devono essere committati: le attività operative vanno tracciate nel piano di stabilizzazione o nelle issue e pull request GitHub.
