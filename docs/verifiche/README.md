# Verifiche storiche

Questa directory conserva i rapporti di verifica prodotti durante le release e le iterazioni UX precedenti a **v0.20.4**. Sono evidenze storiche: descrivono il codice, gli strumenti e i limiti disponibili al momento della loro redazione e non costituiscono un gate di release corrente.

Per stabilire lo stato pubblicabile di Binario usare, in ordine:

1. il piano attivo in [`../PIANO_STABILIZZAZIONE_v0.20.4.md`](../PIANO_STABILIZZAZIONE_v0.20.4.md);
2. i workflow in [`.github/workflows/`](../../.github/workflows/);
3. la documentazione operativa corrente sotto [`../`](../);
4. solo come contesto genealogico, i documenti di questa directory.

I nuovi rapporti devono riportare commit, comandi eseguiti, ambiente ed esito e devono essere salvati qui anziché nella radice del repository.
